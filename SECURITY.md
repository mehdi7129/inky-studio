# Security

For a security issue, use [GitHub’s private vulnerability reporting form](https://github.com/mehdi7129/inky-studio/security/advisories/new). Include the iOS build or backend version, the affected component and what you observed. Remove real QR payloads, credentials, private keys and personal photos. Use [Issues](https://github.com/mehdi7129/inky-studio/issues) for ordinary bugs and feature requests.
